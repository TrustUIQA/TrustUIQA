# TrustUIQA

Code and data for **Do Underwater Image Quality Metrics Agree with Human Perception? A Benchmark with Human Choices, Simple Edits and Generative Drift**

Rishii Kumar Singh, Abhinav Rajput, Dinesh Kumar Vishwakarma
Delhi Technological University, Delhi, India

## Status

Release in progress. This repository will contain:

- Evaluation code for within-scene agreement (Cohen's kappa) of 73 NR-IQA metrics on five human references
- The choices from our paired-comparison study
- The scores of every metric on every image
- Scripts that download the published opinion-score sets and UIEB and rebuild our edits, attacks and generative drift images

The benchmark data will be at https://huggingface.co/datasets/TrustUIQA/TrustUIQA

The opinion-score sets and UIEB remain with their authors and are not redistributed here.
