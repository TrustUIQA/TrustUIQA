# MV-UIQD
We propose MV-UIQD, the first underwater image quality assessment (UIQA) benchmark with task-aware metrics that reliably predict detection and segmentation accuracy, thus exposing and narrowing the human–machine perception gap.
The MV-UIQD can be donwload from:[https://drive.google.com/file/d/1BVLnpwSByTdaBfUA7DocciUKirIkpJk_/view?usp=drive_link]. We train the UIQA models PAUQA (https://github.com/CatchACat083/PAUQA), EDANet (https://github.com/yia-yuese/EDANet), ATUIQP (https://github.com/YT2015?tab=repositories), URanker (https://lichongyi.github.io/URanker files/), and Twice-Mixing (https://github.com/zhenqifu/Twice-Mixing) for 100 epochs with the random seed set to 42.
The full dataset will be made publicly available upon acceptance of the paper.
